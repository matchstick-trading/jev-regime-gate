# Jev Regime Screener

EOD market regime screener powered by [TypeSafe Jev](https://typesafe.ai). Displays daily SPY regime classifications, confidence scores, and gate decisions in a NinjaTrader Market Analyzer-inspired data grid.

**Research experiment, not investment advice.**

## Stack

React 19 · Tailwind 4 · Vite · TypeScript

## Dev

```bash
npm install
npm run dev
```

Data lives in `public/spy-screener.json` — generated from the parent project's classified feed.
